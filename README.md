# Accuracy-of-Consumer-Grade-Activity-Monitors-for-Measuring-VO2max
Can we trust our handy dandy smartwatches to predict your cardiorespiratory fitness? Analyze and find out!
Welcome to this repository where we'll be exploring whether or not we can confidently rely on consumer-grade activity monitors to predict VO2max, an important health marker
Please open the Excel file associated with this project and lets begin!
I'd recommend grouping all the various kinds of models into one group based on the brand (i.e., all Garmin models would be classified as 1, Apple Watch models as 2, etc.)
Additionally, we asked all of our participants to complete a questionnaire as seen on the left side of the Excel sheet. You can run non-parametric tests and regression models to see how these impact accuracy.
Good luck!
